- `first-rehearsal.py` + `.sh`: one SSH session; phases identity gate, prereq, snapshot, empty install, verify, exact uninstall, restore proof, connectivity. Subcommands plan/execute; config keeps real data outside repo (`config.example.json` uses 02:00:00:00:00:xx, 192.0.2.0/24).
- `penn-pilot.py` + `.sh`: gate 3 of docs/integration-004.md; reuses rehearsal helpers (`cfr_*`). `penn_pilot_v2.py`: schema v2 pieces (roles, policy validator, legs, v2 phase timing, digest rules), loaded by penn-pilot.py (not a script). `penn_pilot_leg2.py`: v2 leg-2 pty driver (marker watcher, `ssh -tt` commit legs, digest-bound argv), also loaded by penn-pilot.py.
  Schema v2 phases: PAYLOAD, IDENTITY, PREREQ, SNAPSHOT, BASELINE, INSTALL (floor-only scoped activation), ENROLL, SCOPE-ADD-1/2, PAUSE, RESUME, MOVE, BULK, EXPIRY, DNS, INVENTORY, SCOPE-REMOVE, UNINSTALL, RESTORE, CONNECTIVITY; optional SCOPE precedes SCOPE-ADD-1. Four digest-bound PTY commit legs run once, with cancellation acknowledgement before teardown.
  Usage: `plan CONFIG` then `execute CONFIG --expect-plan-sha256 HEX`. After MUTATION_BEGIN the procedure attempts its single teardown when the installed recovery script exists; the deliberately unbounded installer may outlive remote timeout. M4b blocks first rehearsal/permanent install.
  Result lines: PENN_PILOT_PASS / PENN_PILOT_STOPPED_RESTORED[_CONNECTIVITY_FAILED]; PENN_KERNEL_STATE paused|clear|unknown.
